# 祥能人员与招聘信息管理系统统一交付质检报告

质检时间：2026-07-22 18:15（Asia/Shanghai）  
质检结论：**允许交付**

## 1. 范围完成度

- 原个人端、内部管理端、供应商端与管理后台保留，统一接入 PostgreSQL 正式业务服务层。
- 新增本地 `Qwen3.5 4B + Ollama` AI 助手，管理后台使用右侧抽屉，移动端使用全屏抽屉。
- AI 固定实现项目人员数据、人员信息、招聘进度、单人入职、单人离职五项能力。
- 查询读取实时系统数据；模型只做意图和参数；程序完成权限、Schema、实体匹配、查数和计算。
- 入职与离职具备预览、用户确认、用户绑定 token、有效期、权限复核、Serializable 事务、幂等和审计日志。
- 不提供自由 SQL、批量入离职、删除以及工资或结算写入。
- 本地演示数据库、模型、服务均有一键启动/停止流程；压缩包保留可重复导入的完整演示数据，不包含本机数据库实例和模型权重。

## 3. 数据与安全核查

- 演示数据导入结果：8 个分公司、309 个项目、457 个供应商、156 个岗位、17,180 个人员、18,841 条报名。
- 当前在职 4,437 人、待入职 3,802 人、离职 4,236 人；AI 与传统页面读取同一数据库和业务口径。
- AI 写操作验证结束后执行演示快照重置，未遗留测试入离职状态。
- 演示登录使用后端签发的真实 JWT；旧版静态演示 token 只用于历史浏览器状态自动迁移，正常登录和查询不会走静态数组。
- 浏览器不保存或调用模型密钥；模型地址和配置仅由后端环境变量读取。

## 4. 保留性与界面检查

- 未删除原管理后台、Taro 小程序、小官网、导入工具或传统人员生命周期入口。
- UI 沿用参考图的蓝白主色、圆角卡片、指标宫格、移动顶部栏、四栏底部导航和悬浮 AI 入口。
- 缺少正式薪资字段时显示“薪资面议”，不使用参考图演示金额伪装真实数据。
- 入离职预览取消后按钮锁定，防止误确认；执行成功后同样锁定并通过幂等键防止重复提交。

## 5. 非阻断风险

- 管理后台生产构建存在主包大于 500 kB 的性能提示；不影响启动和业务正确性，后续可继续按页面拆包。
- 本地 4B 模型的复杂语义兜底速度受 CPU/GPU 性能影响；强规则查询不依赖模型，模型超时会转标准表单。
- 演示库仅用于比赛/验收；部署正式环境前必须更换 JWT secret、管理员初始密码，关闭 `AI_DEMO_MODE` 并重新执行权限验收。
- 历史源码曾出现的第三方 Agnes 凭据已从当前源码移除；仍应在原服务后台撤销或轮换该历史凭据。
