# 审批流程快速搭建手册

## 1. 设计原则

审批流页面采用按顺序排列的节点卡片。管理员不需要绘制复杂流程图，只需添加审批环节、选择审批对象、设置可选条件、调整顺序、预览并发布。

## 2. 搭建步骤

1. 新建流程，填写名称、编码和适用业务；
2. 点击“添加审批环节”；
3. 为每个环节填写名称；
4. 选择审批对象：部门负责人、直属上级、财务审核、系统管理员、指定角色、指定岗位或指定人员；
5. 设置处理时限和是否允许退回；关闭“允许退回”后，该环节只能通过或驳回；
6. 使用“上移”“下移”调整环节顺序；
7. 有分流需求时打开“适用条件”；
8. 输入测试金额和风险等级，点击预览流程；
9. 保存草稿；
10. 确认后发布。

## 3. 条件规则

条件支持金额、风险等级、组织/部门、经营分公司、项目、供应商、发起人角色和数据范围。比较方式包括等于、不等于、大于、大于等于、小于、小于等于、属于和包含。

关闭条件时，所有申请都经过该环节。条件不满足时，该环节自动跳过，预览结果会明确显示“已跳过”。

## 4. 版本规则

- 草稿可以反复修改；
- 每次保存形成新版本；
- 发布新版本后，新申请使用新版本；
- 已经进入审批的申请继续使用发起时的旧版本；
- 旧审批记录和审批意见不可因模板修改而被覆盖；
- 退回会结束当前审批实例并标记为已退回，业务发起人修正后重新提交，避免流程停在没有待办人的悬空状态。

## 5. 使用建议

- 普通流程尽量控制在 2 至 4 个审批环节；
- 金额或高权限申请再增加领导审批，避免所有申请都走最长链路；
- 指定岗位时，系统从当前在职且已绑定账号的岗位人员中确定审批人；
- 发布前必须用典型金额和高低风险各预览一次。
