# 祥能 HRMS 内部真实数据系统使用说明

## 一、环境定位

本版本用于公司内部私有运行，读取真实人员、项目、组织和银行卡数据。不得将 `data/internal-source/`、`data/internal/` 或员工初始账号文件上传到公开网站、公开仓库或公开演示分支。

公开演示与内部系统是两套数据环境：

- 内部系统：真实数据，关闭演示令牌和合成数据回退；
- 公开演示：仅使用合成数据，不承载公司真实身份证、电话和银行卡。

## 二、当前真实数据来源

系统每次内部启动前重新读取：

1. `data/internal-source/祥能人力周度在离职数据统计_20260719.xlsx`
2. `data/internal-source/所有企业名单汇总2026-07-21.xls`
3. `data/internal-source/202606集团花名册.xlsx`

标准化结果：

- `data/internal/real-business-data.json`
- `data/internal/real-business-data-reconciliation.json`

当前标准化数据包括：

- 20个组织单元；
- 8个项目经营区域；
- 223个项目；
- 415名派遣、外包或候选人员；
- 430条报名、面试或入职过程；
- 61条岗位需求；
- 127名内部员工；
- 129条内部任职记录。

另有29条源记录无法从现有表格确认项目经营归属，系统保留在待核验清单中，不自行猜测。

## 三、启动前提

Windows电脑需要：

- Node.js 22；
- pnpm 11.7；
- 可运行的PostgreSQL；
- 项目依赖已安装；
- 三份真实源文件位于上述固定目录。

内部数据库固定与公开演示数据库隔离，默认数据库名为 `xiangneng_hrms_internal`。

## 四、启动与停止

在项目根目录执行：

```powershell
pnpm internal:start
```

脚本依次完成：

1. 检查真实源文件；
2. 重新生成标准化真实数据；
3. 检查内部数据库和端口；
4. 执行数据库迁移；
5. 幂等导入组织、项目、人员、岗位需求和内部员工；
6. 创建或关联真实内部员工账号；
7. 创建内部管理员；
8. 启动API、管理后台和员工门户；
9. 强制关闭演示令牌与假数据回退。

停止系统：

```powershell
pnpm internal:stop
```

## 五、账号

活动状态的真实内部员工可自动创建系统账号。账号清单写入：

`data/internal/internal-employee-initial-accounts.json`

该文件包含初始登录信息，只能在内部安全保存，不得公开上传。已经绑定账号的员工不会在重复启动时被覆盖密码。

内部管理员账号由启动脚本要求现场输入，密码长度至少12位，不在代码中写死。

## 六、报销操作

### 员工小程序

员工进入“报销中心”后可：

- 发起报销；
- 录入费用明细；
- 上传付款凭证和发票；
- 保存草稿并提交；
- 查看部门、负责人、财务审核状态；
- 查看审核通过金额；
- 查看待付款或已付款状态。

### 部门和财务

系统按员工真实组织归属和月份自动汇总，生成：

1. 按费用类型汇总；
2. 按报销人汇总；
3. 逐笔费用明细；
4. 报销人与审核金额付款名单。

部门和财务不需要重新录入或再次手工加总。明细调整后，所有汇总自动更新。

### 当前自动校验

系统已经自动处理：

- 金额必须为正数；
- 付款金额与申报金额勾稽；
- 发票金额满足规则；
- 付款凭证和发票附件完整；
- 同一文件SHA256精确重复；
- 明细与批次合计一致；
- 审核通过金额不能超过申报金额；
- 实际付款金额应与审核通过金额一致。

当前尚未接入发票OCR、发票号码联网核验和裁剪图片相似查重，不能把精确文件哈希误称为万能发票识别。电脑也有尊严，没写的功能不能靠命名召唤出来。

## 七、真实数据更新

后续源表更新后，将新文件替换到固定目录，再重新执行 `pnpm internal:start`。导入程序按稳定业务标识更新已有组织、项目、岗位需求和人员过程，不要求人工清空数据库后重录。

任何无法从源表确定的归属保持待核验，不自动编造。

## 八、验收重点

首次在公司电脑运行时，应重点核验：

- 组织树与公司当前组织架构一致；
- 内部员工人数、岗位、部门和银行卡正确；
- 项目、人员和状态数量与源表一致；
- 普通员工能在小程序看到“我的报销”；
- 部门负责人能看到本部门汇总；
- 财务能看到费用类型、报销人、明细和付款名单；
- 公开演示无法读取真实数据目录。
