# 内部人事与报销融合底座

## 本次范围

本次提交把内部人员、组织关系、复合业务权限和报销流程纳入现有 Fastify/Prisma/React 单体，不创建第二套系统。

### 内部人事

- 组织中心和部门；
- 内部员工档案；
- 花名册预览和确认导入；
- 账号开通、重新启用和密码重置；
- 人员停用、离职归档；
- 部门、岗位、职级和合同主体变更；
- 部门调动时自动关闭原部门范围权限；
- 多业务角色及部门、分公司、集团数据范围；
- 错误人员记录物理删除保护；
- 操作审计和人员变更历史。

### 报销

- 部门批次与个人提交单两层结构；
- 项目选填；
- 发票和付款凭证分开存储；
- 发票金额必须严格大于付款金额；
- 三张表由同一套明细实时生成；
- 付款凭证和发票分别生成打印顺序；
- 固定七个批次状态；
- 问题标记与主状态分离；
- 状态不能跳级或回退；
- 有未解决问题时不能整批通过；
- 整批进入待打款和已打款；
- 乐观锁防止多人同时改状态。

## 管理端入口

- `/internal-hr`：内部人员、账号、转移、停用、业务授权和花名册导入；
- `/reimbursements`：批次、三张表、两套打印顺序、问题处理和状态流转。

## 数据安全

用户确认内部人事字段不做脱敏，但接口仍通过权限和数据范围限制访问。真实集团花名册不进入 Git 仓库，`.gitignore` 已增加对应规则。
